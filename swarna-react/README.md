# Swarna Fine Jewellery - React Frontend

React + Vite responsive jewellery website with mobile-first layout, hover effects, scroll animations, 10 jewellery collection images, reviews, location map, WhatsApp/Instagram/Facebook buttons and responsive navigation.

## Run
npm install
npm run dev

## Build
npm run build

Edit contact details and social links in `src/main.jsx`. Replace external images with licensed/local assets for production.
